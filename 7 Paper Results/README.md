# Paper figures and tables

Complete the [environment setup](<../1 Environment/README.md>) and [artifact restoration](<../4 Trained Models/README.md>), then run from the repository root:

```bash
python -B "7 Paper Results/reproduce_paper.py"
```

This CPU command reconstructs Figures 1–10 and Tables 1–5 from archived results without training models. The PDF/PNG figures, TeX tables and `reproduction.json` are written to `7 Paper Results/2 Outputs/<timestamp>/`.

Use `--family iris` or `--family ki67` for a subset, `--tag <new-name>` to name the output directory, and `--dry-run` to inspect the commands. Existing editions are never overwritten. Figures are exported as vector PDFs and 600-dpi PNGs.

| Paper item | Generator | Evidence |
| --- | --- | --- |
| Figures 1–6 | [Iris figures](<1 Generators/condensed_figures.py>) | Archived Iris learning curves, probabilities and regression predictions |
| Tables 1–2 | [Iris tables](<1 Generators/iris_tables.py>) | Four complete out-of-fold (OOF) evaluations per row from core/full aggregates |
| Figures 7–8, Table 3 | [Joint Ki-67 results](<../6 Ki67/2 Source/paper_joint.py>) | Twelve joint three-class fits, with combined and per-dataset tests |
| Figure 9 | [Binary Ki-67 matrices](<../6 Ki67/2 Source/paper_binary_confusions.py>) | Initial and selected predictions at three binary thresholds |
| Table 4 | [Binary Ki-67 table](<../6 Ki67/2 Source/paper_binary_table.py>) | Separate-model metric summary |
| Figure 10, Table 5 | [Native-RGB comparison](<../6 Ki67/2 Source/paper_rgb.py>) | Native-RGB three-class fits and frozen-feature comparisons |

Iris plot data come from `5 Iris/5 Outputs/paper-results/results-20260914T025839Z-ilnj5d7n/`. Ki-67 uses archived histories and initial/selected predictions. The [figure catalog](<../4 Trained Models/1 Catalogs/figure-provenance.json>) identifies the manuscript PDFs.
